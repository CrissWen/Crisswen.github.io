# Каталог аудіоресурсів TrueBunker (`/audio`)

Ця директорія призначена для зберігання аудіофайлів гри, розділених за каналами гучності (`ui`, `sfx`, `music`):

## Структура файлів
- **`/audio/ui/`** (або `/audio/sfx/ui/`) — Інтерфейсні звуки:
  - `ui-click.wav` — тактильний клік кнопок та вкладок
  - `lock-toggle.wav` / `.mp3` — клацання замка відкриття/приховування характеристики
  - `lock-hover.wav` — легке наведення на замок характеристики
  - `tab-switch.mp3` — перемикання вкладок
  - `dice-roll.wav` — кидок кубика при перевірках
- **`/audio/sfx/`** — Ігрові звукові ефекти:
  - **`/audio/sfx/roulette/`** — Рулетка:
    - `click.mp3` — клацання стрічки рулетки
    - `choose.mp3` — результат рулетки
  - **`/audio/sfx/bunker-inside/`** — Всередині бункера:
    - `timer-tick.mp3` — цокання таймера на останніх секундах
    - `bunker-ambient.mp3` — низькочастотний гул / атмосфера бункера
  - **`/audio/sfx/bunker-door/`** — Кінематографічний перехід гермодверей:
    - `cataclysm-siren.wav` — сирена або тривожне оповіщення
    - `bunker-door-close.wav` — важке насування бронестулок
    - `bunker-door-slam.wav` / `.mp3` — нищівний удар зачинення шлюзу
    - `bunker-hydraulic.wav` — замикання ригелів та гідравліка
    - `bunker-door-open.wav` — розгерметизація та відкриття шлюзу

## Покроковий чек-лист: Як додати новий звук без помилок

1. **Покладіть аудіофайл на диск**:
   - Формати: `.mp3` або `.wav` (для сучасних браузерів також підходить `.webm`).
   - Покладіть файл у відповідну папку (`/audio/ui/`, `/audio/sfx/` тощо).
2. **Оновіть запис у `js/constants/sounds.js`**:
   - `src`: точний шлях до файлу відносно кореня (наприклад `['./audio/ui/ui-click.wav']`).
   - ⚠️ **`preload: true`** — **ОБОВ'ЯЗКОВО виставляйте `true`**, щойно файл додано на диск!
     *(Якщо залишити `preload: false`, браузер почне завантажувати файл лише в момент кліку, через що перший клік буде повністю «німим» або скасується)*.
   - `baseVolume`: коефіцієнт від `0.0` до `1.0`.
     - Для коротких імпульсних звуків (кліки кнопок, клацання замків) ставте **`0.8` – `0.9`**, оскільки вони дуже короткі й при низьких значеннях не чутні у міксі каналу (`uiVolume * masterVolume`).
     - Для тривалих або гучних звуків (сирени, шлюз, ембієнт) — `0.4` – `0.7`.
   - `channel`: `AUDIO_CHANNELS.UI`, `AUDIO_CHANNELS.SFX` або `AUDIO_CHANNELS.MUSIC`.
   - `throttleMs`: мінімальний кулдаун між викликами (захист від какофонії при спам-кліках).
3. **Перевірте відтворення**:
   - В інженерній **Аудіо-лабораторії (`audio-lab.html?dev=1`)**.
   - У вкладці **Профіль (`#/profile`) → «Звук»** через тестову кнопку ▶.
   - Або через консоль браузера (F12): `soundManager.play('id-звуку')`.

## Важливі підводні камені та нюанси браузерів

### 1. Браузерна політика Autoplay (AudioContext Suspended)
- Будь-який сучасний браузер (Chrome, Edge, Firefox, Safari) за замовчуванням блокує виведення аудіо на динаміки до **першого фізичного кліка або натискання клавіші на самій вебсторінці**.
- Якщо ви щойно відкрили сторінку, відкрили DevTools (F12) і написали в консолі `soundManager.play(...)` — консоль поверне числовий ID (наприклад `1002`), але звуку не буде, бо клік у консолі не вважається жестом на сторінці!
- **Вирішення**: зробіть хоча б один клік мишкою по фону сайту або по будь-якому елементу, і звук назавжди розблокується для всієї поточної вкладки.

### 2. Чому `preload: true` критичний для ігрових звуків
- Коли `preload: false`, Howler не завантажує байти звуку в пам'ять.
- Коли користувач натискає кнопку, `howl.play()` надсилає асинхронний HTTP-запит. Завантаження та декодування займає 100–300 мс.
- Якщо за цей час користувач встигає натиснути щось інше, Howler через `interrupt: true` перериває попереднє завантаження. Результат — враження, що кнопки «глухі».
- **Правило**: якщо звуковий файл фізично існує в проєкті — завжди вказуйте `preload: true`. `preload: false` потрібен лише для тих слотів звуків, файли яких ще не записані/не створені.

### 3. Процедурний синтезатор-фоллбек (`js/services/audio-synth.js`) та Аудіо-лабораторія (`audio-lab.html`)
- Якщо для звуку ще немає готового аудіофайлу на диску, або файл не вдалося завантажити (офлайн, мережевий збій), `soundManager` автоматично делегує генерацію звуку процедурному синтезатору `AudioSynth` на чистому Web Audio API (`js/services/audio-synth.js`).
- Для візуального та слухового A/B тестування всіх 14 звуків створено інженерну **Аудіо-лабораторію (`audio-lab.html`)**:
  - Захищена **Admin Gate** (доступна адміністраторам через Supabase або локально через `audio-lab.html?dev=1`).
  - Підтягує звуки напряму з `SOUND_CATALOG` (`js/constants/sounds.js`).
  - Має живий осцилограф та FFT-спектрограф у реальному часі, чисті векторні SVG-іконки та кнопки `[Семпл]`, `[Синтез]` і `[A/B]` для порівняння оригінального файлу з синтезованим дублером.
