# Каталог аудіоресурсів TrueBunker (`/audio`)

Ця директорія призначена для зберігання звукових файлів гри, розділених за каналами:

- **`/audio/ui/`** — Інтерфейсні звуки:
  - `lock-hover.mp3` / `.webm` — наведення на замок характеристики
  - `lock-toggle.mp3` / `.webm` — відкриття / закриття замка
  - `click.mp3` / `.webm` — стандартний клік кнопки
  - `tab-switch.mp3` / `.webm` — перемикання вкладок
- **`/audio/sfx/`** — Ігрові звукові ефекти:
  - `dice-roll.mp3` / `.webm` — кидок кубика
  - `card-reveal.mp3` / `.webm` — розкриття характеристики гравця
  - `vote-cast.mp3` / `.webm` — зарахування голосу
  - `timer-tick.mp3` / `.webm` — цокання таймера на останніх секундах
  - `timer-end.mp3` / `.webm` — завершення часу таймера
  - `cataclysm-siren.mp3` / `.webm` — сирена або оповіщення катаклізму
  - `player-kick.mp3` / `.webm` — вигнання гравця з бункера
- **`/audio/music/`** — Фонова музика та ембієнт:
  - `bunker-ambient.mp3` / `.webm` — фоновий гул / атмосфера бункера

## Як підключити новий звук
1. Покладіть аудіофайл (рекомендовано `.mp3` або пару `['.webm', '.mp3']`) у відповідну підпапку.
2. Зареєструйте або оновіть запис у `js/constants/sounds.js`, виставивши:
   - `baseVolume` (від `0.0` до `1.0`) — точкове калібрування гучності семплу відносно інших звуків.
   - `channel` (`ui`, `sfx`, `music`) — канал гучності.
   - `throttleMs` — мінімальний інтервал між повтореннями (для захисту від какофонії).
3. Викличте у коді: `soundManager.play('ключ-звуку')`.

*Примітка:* Якщо файл фізично відсутній у папці `/audio`, `soundManager` автоматично відтворює синтезований Web Audio сигнал-плейсхолдер (`synthType`), щоб логіку та мікшер гучності можна було тестувати без очікування готових аудіофайлів.
